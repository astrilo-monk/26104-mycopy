LOCAL RUN COMMANDS
==================

PREREQUISITES
-------------
Install Java 25, Maven, Python 3.10+, Node.js 20+, and configure a Supabase
Postgres database. Keep four PowerShell terminals open while developing.


ONE-TIME: CONFIGURE PYTHON SERVICES
-----------------------------------
Run this once from the repository root:

cd C:\Users\mdowa\OneDrive\Desktop\26104-gpt\aasist_repo
Copy-Item .env.example .env
notepad .env

Set these values in aasist_repo\.env before starting anything:

SECRET_KEY=replace-with-one-long-random-secret-shared-by-all-services
AUTH_DATABASE_URL=postgresql+psycopg://YOUR_USER:YOUR_URL_ENCODED_PASSWORD@YOUR_SUPABASE_HOST:5432/postgres
CORS_ALLOWED_ORIGINS=http://localhost:5173

Use the SAME SECRET_KEY in the Spring Boot terminal below.


TERMINAL 1: SPRING BOOT API
---------------------------
cd C:\Users\mdowa\OneDrive\Desktop\26104-gpt\voice-cloning-backend

$env:SECRET_KEY = "replace-with-the-same-secret-from-aasist_repo-dot-env"
$env:SUPABASE_DB_URL = "jdbc:postgresql://YOUR_SUPABASE_HOST:5432/postgres"
$env:SUPABASE_DB_USER = "YOUR_DATABASE_USER"
$env:SUPABASE_DB_PASSWORD = "YOUR_DATABASE_PASSWORD"
$env:CORS_ALLOWED_ORIGINS = "http://localhost:5173"

mvn spring-boot:run

Leave this terminal running. Spring starts at http://localhost:8080


TERMINAL 2: LOGIN API
---------------------
cd C:\Users\mdowa\OneDrive\Desktop\26104-gpt\aasist_repo

py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r login_system\requirements.txt
uvicorn login_system.main:app --port 8001 --reload

Leave this terminal running. Login starts at http://localhost:8001


TERMINAL 3: AASIST INFERENCE API
--------------------------------
cd C:\Users\mdowa\OneDrive\Desktop\26104-gpt\aasist_repo

.\.venv\Scripts\Activate.ps1
pip install -r inference_api\requirements.txt
$env:SPRING_BOOT_URL = "http://localhost:8080"
uvicorn inference_api.main:app --port 8000 --reload

Leave this terminal running. Inference starts at http://localhost:8000


TERMINAL 4: FRONTEND
--------------------
cd C:\Users\mdowa\OneDrive\Desktop\26104-gpt\frontend

Copy-Item .env.example .env
npm install
npm run dev

Open the URL Vite prints, normally http://localhost:5173


OPTIONAL: QUICK HEALTH CHECKS
-----------------------------
Run these in another PowerShell terminal after all services are running:

Invoke-WebRequest -UseBasicParsing http://localhost:8001/
Invoke-WebRequest -UseBasicParsing http://localhost:8000/health

Notes:
- Do not put SECRET_KEY or database credentials in frontend\.env.
- The inference /health request loads the model and can take a little longer.
- On a fresh database, creating the first account through the frontend creates
  the users table automatically.
